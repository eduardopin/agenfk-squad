Photo uploads

A worked example on a fictional product: a field app that uploads photos and gets thumbnails back. Nothing here is a real system; the inventory below shows the form a real one takes.

The path of a photo

  1. The app sends the photo to API Gateway over HTTPS with the user's token.
  2. API Gateway invokes the upload function, which checks size and type.
  3. The upload function stores the photo in the S3 bucket and answers the app.
  4. S3 sends an object-created event to the SQS queue.
  5. The thumbnail function takes the events in batches of ten.
  6. It writes the thumbnail to S3 and records the photo in DynamoDB.
