The path of a request

  1. The user calls the API. The request goes through CloudFront, which also serves the static files from S3.
  2. The load balancer hands the request to a task in either of the two zones.
  3. The API writes to the primary RDS; the standby replica receives the copy in the other zone.
  4. Whatever needs no immediate answer goes to the SQS queue.
  5. The Lambda function consumes the queue.
  6. The Lambda writes the job state to DynamoDB.
