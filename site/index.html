The failure pattern

Reasonable sessions add up to an unreasonable system.

The limits began with one measured week—not a benchmark, and not a claim about anyone else’s machine.

  1. 01 / context cost 420k–966k

    Context is repaid every turn.

    The orchestrating sessions carried hundreds of thousands of context tokens while deciding for themselves when to stop.

  2. 02 / unbounded fan-out 249 sub-agents

    Spawns look free from inside the session.

    Sub-agents consumed 64% of all tokens measured that week.

  3. 03 / repeated review 5× one card reviewed

    One card was sent to review five times.

    That is the measurement. Separately, the observed failure pattern was self-approval: authors judging their own work.

  4. 04 / merge collisions 5 projects overnight

    Every merge moves the floor.

    Five projects orchestrated at once. Without a turn, each session can resolve against a version of the default branch that is about to move.

Measured over one week, one machine, five projects. Source: README, “The problem”.

How it fits together

Prompts define the jobs. Hooks enforce the traffic rules.

AgenFK owns the card and evidence. The squad owns role boundaries. The watcher owns context, dispatch, session switches with herdr, and merge turns.

01

Roles with explicit boundaries

Each agent gets a job and a tool list. Writers gate on one card; the independent verifier has no Edit/Write tool and receives the branch, not the author’s story. The no-writing roles still have Bash, so that boundary remains a prompt rule.

02

A watcher that measures

The Python hook reads transcript usage, applies the same handoff arithmetic as the session report, and treats its capitalized messages as a text API.

03

A way out of every refusal

A denial says where work continues: in the current session, after a clean handoff, when a slot frees, or with an explicit owner decision.

04

A local merge queue

Sessions request a turn. When MERGE TURN arrives, that session fetches, merges the default branch once, runs the suite, pushes, and lands.

The twelve agents

One role each. Limits included.

The catalogue is Markdown. A project-specific agent with the same name replaces the squad default.

productplans

Find the smallest usable increment.

Reads the repo and board, then creates checkable cards in TODO.

githubclaims only

Map branches, worktrees, and fronts.

Plans disjoint parallel work and the merge train; never merges.

developerwrites

Turn one card into code.

One branch and worktree, with the project suite as the gate.

frontendwrites

Own interface and visual quality.

Builds screens, components, systems, motion, and visual pieces.

design-bridgewrites

Carry design across tools.

Moves motion and visual assets between code, Figma, Claude, GPT, and ComfyUI.

testertests only

Prove each new test can fail.

Writes tests for one card and records the mutation evidence.

verifierno Edit/Write

Review from clean context.

Runs review, adversarial checks, and verification; returns SHIP, FIX_FIRST, or REJECT.

infraplan only

Write infrastructure, stop at plan.

Handles CI/CD, Terraform, Dockerfiles, and migrations; never applies or deploys.

finopsno Edit/Write

Price engineering choices.

Sources cloud cost and measures token and CI spend.

financeno Edit/Write

Connect cost to the product.

Works from sourced data on pricing, margin, break-even, and runway.

gtmdrafts only

Draft the route to a user.

Positioning, landing copy, outreach, and demos; never publishes or sends.

contexthandoffs only

Decide when a session should move.

Measures context, burn, rereading, loops, and verified pickup state.

The watcher speaks in exits

A refusal is only useful if work knows where to go.

This is example output from hooks/squad-watch.py over a synthetic transcript with an artificial 550k context value in a throwaway home.

watcher output
[squad-watch] PROACTIVE HANDOFF — context 550k/1.0M (55%), burn 60% of the budget, reread 90%, each turn rereads 55k weighted tokens, a new session pays for itself in 1.2 turn(s). When you close the step in progress, without asking permission and without starting a new front: (1) record on the card what was decided (`agenfk comment <id> "PAUSE: done X, remaining Y, next Z"`); (2) write the handoff with mode A of the `clear-pickup` skill (ground truth by command, short, UNKNOWN for whatever you did not verify; under Next step, what remains of the current request, in order); (3) end your reply with the handoff path and stop. Tell the owner: `/clear` and then `/clear-pickup pickup`.

Install

Put the squad at the user level.

The installer checks prerequisites, installs the latest stable release, links the agents and hooks into Claude Code, and registers the hook manifest. It refuses to overwrite real files.

Needs git, curl, bash and Python 3.10 or newer; the installer warns if Claude Code or AgenFK are missing. Developed and run daily on Linux; macOS is untested; WSL behaves like Linux when Claude Code runs inside WSL. Windows 10/11 has its own installer and CI job.
